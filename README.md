# -Sistema-de-Alerta-Temprana-para-Incendios-Forestales-Post-Heladas-Enfoque-One-Health-
Este repositorio contiene los scripts analíticos y de procesamiento diseñados para el desarrollo de un **Sistema de Alerta Temprana (SAT) orientado a incendios forestales post heladas**, integrando la perspectiva multidisciplinaria de *One Health*.
