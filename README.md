# Sistema de Alerta Temprana para Incendios Forestales Post Heladas (Enfoque One Health)

Repositorio oficial de scripts y código fuente desarrollados en el marco de la investigación doctoral en **Ciencias de la Salud con enfoque One Health**.

## 📌 Descripción del Proyecto
Este repositorio contiene los scripts analíticos y de procesamiento diseñados para el desarrollo de un **Sistema de Alerta Temprana (SAT) orientado a incendios forestales post heladas**, integrando la perspectiva multidisciplinaria de *One Health*. 

El sistema evalúa cómo las condiciones climáticas extremas (heladas seguidas de periodos de sequía o estrés térmico en la biomasa) incrementan la vulnerabilidad de los ecosistemas, impactando indirectamente en la salud pública (calidad del aire, enfermedades respiratorias, seguridad alimentaria) y la interfaz humano-animal-ambiente.
